# EchoSign AI

## Overview
EchoSign AI is a Python application designed for sign language recognition and speech processing. It utilizes computer vision and machine learning to interpret sign language gestures and convert them into speech, providing an interactive user experience.

## Features
- Real-time sign language recognition using a webcam.
- Speech output for recognized signs.
- User-friendly interface built with Tkinter.
- Supports customizable sign language dictionaries.

## Installation

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/my-python-app.git
   cd my-python-app
   ```

2. Install the required dependencies:
   ```
   pip install -r requirements.txt
   ```

## Usage

1. Run the application:
   ```
   python app.py
   ```

2. Use the "Start Sign" button to begin sign language recognition.
3. Use the "Start Speech" button to enable speech output for recognized signs.
